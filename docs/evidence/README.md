## Evidence discipline

Screenshots are supporting proof, not the project itself.

The README and technical documents explain the decisions; evidence validates the claims.

## Claim boundary

The lineage screenshots prove automated file-level lineage and schema-aware visualization.

They do not prove explicit column-to-column lineage edges.
