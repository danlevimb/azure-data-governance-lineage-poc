# Documentation

This directory contains the recruiter-facing technical documentation for the Azure Data Governance & Lineage POC.

Recommended reading order:

| Document | Purpose |
|---|---|
| [architecture.md](architecture.md) | End-to-end Azure architecture, data estate, identities, and access model |
| [governance-model.md](governance-model.md) | Classification, stewardship, glossary, and human-review decisions |
| [validation-summary.md](validation-summary.md) | Final validation matrix, scan progression, and persistence test |
| [troubleshooting.md](troubleshooting.md) | Engineering lessons from implementation and diagnostics |
| [evidence/README.md](evidence/README.md) | Curated public evidence pack and claim boundaries |

## Documentation principle

The README tells the project story.

The documents in this folder explain the technical decisions.

The evidence pack proves the claims.

That separation is intentional and follows the same documentation discipline used across the Azure portfolio.
